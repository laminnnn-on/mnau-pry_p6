# Практична робота №6 — Валідація даних (Joi + Notyf)

**Тема:** Валідація даних: створення схем Joi для форм і API-запитів.

## Що додано порівняно з ПР №5

- **Joi** — серверна валідація поля `title` (рядок, 3–100 символів, обов’язкове)
- **Notyf** — зелені/червоні сповіщення в браузері
- Форма додавання завдань + кнопки «Змінити статус» / «Видалити»
- Fetch API для AJAX-запитів без перезавантаження сторінки

## Запуск

```bash
npm install
npm start
```

Відкрий: http://localhost:3000/tasks

## API

| Метод  | Шлях           | Валідація          | Успіх | Помилка |
|--------|----------------|--------------------|-------|---------|
| POST   | /api/tasks     | Joi (title)        | 201   | 400     |
| PUT    | /api/tasks/:id | idSchema           | 200   | 400/404 |
| DELETE | /api/tasks/:id | idSchema           | 200   | 400/404 |
| GET    | /api/tasks     | —                  | 200   | —       |
